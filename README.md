# dtview

`dtview` — терминальная утилита для просмотра бинарных файлов Device Tree Blob (`.dtb`). Она показывает дерево узлов и свойства выбранного узла, интерпретируя значения строк, ячеек и байтов, а также разрешая известные ссылки `phandle` в пути к узлам.

## Возможности

- Навигация по дереву DTB в интерактивном TUI.
- Просмотр свойств в исходном и человекочитаемом режимах.
- Форматирование строковых списков, числовых ячеек, адресов и диапазонов (`reg`, `ranges`), частот (`clock-frequency`, `assigned-clock-rates`) и бинарных значений.
- Переход от ссылочных свойств, таких как `clocks`, `resets`, `interrupt-parent` и `*-supply`, к соответствующим узлам по `phandle`.
- Проверка структуры DTB при разборе; ошибки чтения и некорректного формата выводятся в терминал.

## Требования

- Rust и Cargo (Rust 1.85 или новее для Edition 2024).
- Терминал с поддержкой режима alternate screen и ANSI-управления.
- Файл DTB для просмотра.

## Сборка и запуск

Из корня репозитория:

```sh
cargo build --release
./target/release/dtview path/to/board.dtb
```

Для запуска без отдельной сборки:

```sh
cargo run -- path/to/board.dtb
```

Программа принимает путь к одному файлу DTB как позиционный аргумент. Например, если DTB скомпилирован из исходника Device Tree с помощью `dtc`:

```sh
dtc -I dts -O dtb -o board.dtb board.dts
dtview board.dtb
```

## Управление

| Клавиша | Действие |
| --- | --- |
| `↑` / `k` | Выбрать предыдущий узел |
| `↓` / `j` | Выбрать следующий узел |
| `Enter` / `Space` / `→` | Раскрыть или свернуть выбранный узел (`→` раскрывает) |
| `←` | Свернуть узел или перейти к родителю |
| `Tab` | Переключить режим отображения значений |
| `q` / `Esc` | Выйти |

В режиме `raw` значения показываются в основном в исходном представлении (например, числа — в hex). Режим `human-readable` форматирует частоты в герцах и адреса/размеры для `reg` и `ranges`, используя параметры `#address-cells` и `#size-cells`.
